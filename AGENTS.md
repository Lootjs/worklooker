# Worklooker — заметки для агента

Локальный агрегатор вакансий: Node/TypeScript-сборщик и API (`src/`), интерфейс на Vue (`web/`). Продукт, пользователь и принципы — в `PRODUCT.md`; термины — в `GLOSSARY.md`; визуальная система — в `DESIGN.md`.

## Профиль пользователя

Что искать, решает профиль в `worklooker.local.json` (вне Git). Без него сборщик берёт пример из `worklooker.example.json` и пишет предупреждение в лог сервера. Схема и смысл полей — в `MatchProfile` в `src/local-config.ts`.

Когда пользователь просит настроить поиск под себя или `worklooker.local.json` нет:

1. Соберите материал: резюме или профиль LinkedIn, если пользователь их дал; иначе короткое интервью — целевые роли, область, уровень, ключевые навыки, нужна ли только удалёнка, важна ли русскоязычная среда.
2. Заполните `profile` по образцу примера. Пишите фразы на обоих языках вакансий: `"tech lead"` и `"техлид*"`, `"руководител* разработки"`. Звёздочка в конце слова пропускает русские окончания; слова в фразе разделяются любыми пробелами.
3. Сохраните поле `disabledSources`, если оно уже есть в файле.
4. Проверьте профиль на настоящих вакансиях из `data/vacancies.json` (если файл есть) через `createMatcher` из `src/match.ts`: покажите пользователю, какие прошли и какие нет.

Готово, когда у каждой целевой роли пользователя есть фраза на русском и английском, `pnpm check` проходит, а пользователь подтвердил результат проверки из шага 4.

## Реальные данные

`data/` — решения пользователя (лайки, отклонения) и архив отклонённого. Порт 8787 обычно занят его работающим `pnpm dev`.

- Проверяйте сборщик и API на копии: скопируйте `data/` во временную папку и запустите сервер оттуда с `PORT=<другой порт>`.
- В браузерных проверках интерфейса перехватывайте все не-GET запросы к `/api/**` (`page.route`) до перехода на страницу.

## Код

- Регулярные выражения для текста вакансий пишите с Unicode-границами `(?<![\p{L}\p{N}_])…(?![\p{L}\p{N}_])` и флагом `u`: `\b` в JavaScript не видит кириллицу. Модификатор `(?i:…)` вместе с кириллическим классом V8 сопоставляет неверно — разделяйте регулярки.
- Источник, который отвечает 403, требует входа или капчи, остаётся с ошибкой: защиту сайтов не обходим. Временно выключить источник — `disabledSources` в `worklooker.local.json`.
- GeekJob при частых запросах отдаёт свою страницу «503» с HTTP-кодом 200: к страницам вакансий ходите с паузой (см. `withDetailDescriptions` в `src/scrape.ts`).
- Проверка перед сдачей: `pnpm check` и `pnpm build`.

## Интерфейс

Перед правкой `web/` прочитайте `DESIGN.md` и держитесь его токенов и правил. Для дизайн-задач в проекте есть навык `impeccable` (`.agents/skills/impeccable/SKILL.md`): критика, аудит, типографика, вёрстка, полировка.
