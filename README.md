# Worklooker

Локальный агрегатор вакансий для одного человека. Собирает публично видимые вакансии с сайтов, карьерных страниц и Telegram-каналов в браузере Playwright, отбирает подходящие под ваш профиль, объясняет, почему каждая подошла, и показывает их по одной: «Сохранить» или «Отклонить». Решения хранятся у вас на компьютере и не теряются между сборами.

## Запуск

Нужны Node.js (проверено на 24) и pnpm.

```powershell
pnpm install
pnpm exec playwright install chromium
pnpm dev
```

Откройте `http://localhost:5173` и нажмите «Обновить». Вакансии появляются в очереди по мере того, как отвечают источники.

- **Сохранить** (→ или L) — вакансия уходит в «Лайкнутые» и открывается в фоновой вкладке.
- **Отклонить** (← или X) — вакансия больше не попадёт в очередь. 5 секунд отклонение можно отменить (U).
- **Лайкнутые** листаются прокруткой или ↑/↓; U возвращает вакансию в очередь, → открывает её.

Без режима разработки: `pnpm build && pnpm start`, интерфейс — на `http://localhost:8787`. Собрать без интерфейса (например, планировщиком Windows): `pnpm collect`.

## Ваш профиль

Что искать, задаёт `worklooker.local.json` в корне проекта. Файл не попадает в Git; пока его нет, используется пример `worklooker.example.json` (frontend-роли, только удалёнка).

```json
{
  "profile": {
    "roles": [
      "frontend developer", "front-end lead"
    ],
    "field": ["frontend", "front-end", "vue", "svelte", "javascript", "typescript", "фронтенд*"],
    "seniority": ["senior", "staff"],
    "skills": ["TypeScript", "Vue"],
    "remoteOnly": true,
    "preferRussian": true,
    "minScore": 6,
    "excludeRoles": ["junior", "intern", "стажёр*", "стажер*"],
    "blockers": [],
    "excludeRussia": false,
    "excludeUSA": false,
    "workCountries": [],
    "maxAgeDays": 30
  },
  "disabledSources": []
}
```

Фразы не зависят от регистра, `*` в конце слова пропускает окончания (`руководител*` — «руководитель», «руководителя»). Роли (`roles`) и область (`field`) ищутся только в названии вакансии: в описании часто упоминаются чужие роли и стек компании. Уровень, навыки и признаки удалёнки ищутся во всём тексте; если источник сам сообщает формат работы (удалённо, гибрид, офис), фильтр верит ему. `excludeRoles` отсекает вакансию по названию, `blockers` — по любому месту текста (отрасли, компании). `excludeRussia` отсекает вакансии, где нужно работать из России или работодатель российский: «удалённо по РФ», «по ТК РФ», «аккредитованная IT-компания», «ДМС», «ООО»; зарплата в рублях признаком не считается. `excludeUSA` отсекает вакансии, где нужно работать из США: «US only», «Remote (US)», «Applicants from: USA», «must be based in the US», «authorized to work in the US»; американская компания, которая нанимает по всему миру, не отсекается. Оба флага по умолчанию выключены — включайте те страны, откуда вы не можете работать. `workCountries` — страны, из которых вы работаете, по-английски, как их пишут площадки (`["Kazakhstan"]`): если источник сам указывает, из каких стран принимают кандидатов (так делает Himalayas), вакансии без вашей страны отсекаются, а открытые для всех — остаются. Himalayas ищет по английским ролям из `roles`. Российские работодатели для `excludeRussia` узнаются и по названию: «Магнит», МТС, Сбер, Яндекс, Т-Банк, ВК, Ozon, Wildberries, Авито, «Лаборатория Касперского» (список — в `src/match.ts`). `maxAgeDays` (по умолчанию 30) отсекает старые посты в Telegram-каналах; карьерные страницы компаний показывают только открытые вакансии, их не трогает. Подробно поля описаны в `src/local-config.ts`. Файл читается при каждом сборе — перезапуск не нужен.

Проще всего попросить своего агента (Claude Code, Codex и др.): «настрой профиль Worklooker по моему резюме». Порядок действий для агента описан в `AGENTS.md`.

`disabledSources` временно выключает источники по `id` из `src/sources.ts`. Удобнее делать это во вкладке «Источники»: там видно, сколько вакансий каждого источника прошло профиль в последнем сборе и почему отсеялись остальные.

## Источники

Список — в `src/sources.ts`: Getmatch, GeekJob, HireHi, We Work Remotely, Himalayas, Remocate, Built In, карьерные страницы компаний и публичные Telegram-каналы. Сборщик читает только то, что видно без входа. Если сайт отвечает ошибкой, требует авторизации или показывает капчу, источник помечается как недоступный — защиту сайтов Worklooker не обходит. Пользуйтесь им для личного поиска работы и с уважением к правилам сайтов.

### Личный чат с ботом в Telegram (необязательно)

Чтобы читать сообщения `@wantapply_bot` из своего аккаунта: создайте приложение на [my.telegram.org/apps](https://my.telegram.org/apps), скопируйте `.env.example` в `.env`, впишите ID и hash и один раз выполните `pnpm telegram:login`. Номер, код и пароль 2FA вводятся только в локальном терминале; сессия сохраняется в `data/telegram.session` и в Git не попадает.

## Данные

Всё лежит в `data/` (вне Git): `vacancies.json` — очередь и решения, `rejected.json` — архив отклонённого, `sources.json` — итоги последнего сбора по каждому источнику, `latest.md` — отчёт последнего `pnpm collect`.

## Для разработчиков

- `pnpm check` — проверка типов, `pnpm build` — сборка интерфейса.
- `AGENTS.md` — заметки для coding-агентов, `DESIGN.md` — визуальная система, `PRODUCT.md` — продукт и принципы.
- В `.agents/skills/impeccable` лежит навык для дизайн-задач, `.mcp.json` подключает Playwright MCP.
