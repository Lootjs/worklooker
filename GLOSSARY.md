# Worklooker

Локальный агрегатор, который собирает вакансии из заданных источников и оставляет позиции, релевантные профилю пользователя.

## Language

**Источник**:
Конкретный сайт, карьерная страница или публичный Telegram-канал, из которого Worklooker считывает вакансии.
_Avoid_: Площадка, парсер

**Вакансия**:
Одна опубликованная позиция с заголовком, ссылкой, описанием и происхождением из источника.
_Avoid_: Объявление, карточка

**Профиль**:
Набор ролей, навыков, опыта и ограничений пользователя, по которому оценивается вакансия.
_Avoid_: Резюме, фильтр

**Оценка соответствия**:
Объяснимый балл релевантности вакансии к профилю; он определяет, попадёт ли вакансия в результат.
_Avoid_: Рейтинг, скоринг

**Карточка**:
Одна вакансия в локальном интерфейсе, ожидающая решения пользователя.
_Avoid_: Объявление, слайд

**Лайкнутая вакансия**:
Вакансия, которую пользователь сохранил как интересную; она остаётся доступна во вкладке «Лайкнутые».
_Avoid_: Избранное, принятая

**Отклонённая вакансия**:
Вакансия, которую пользователь решил не рассматривать. Она сохраняется в архиве и не показывается среди новых карточек.
_Avoid_: Удалённая, скрытая
